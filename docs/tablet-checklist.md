# Tablet checklist (PRD §8, M7)

Run on the real tablet, from the **https** address of the hosted app, https://tzoidis.github.io/glossa/ (not the plain-http dev server: install, offline and recording all need https). Tick each item; note the tablet model and OS version.

Tablet: ____________________   OS: ____________   Date: ____________

| # | Check | How | ✓ |
| --- | --- | --- | --- |
| 1 | Installs to the home screen | iPad: Safari → Share → «Προσθήκη στην οθόνη Αφετηρίας». Android: Chrome → ⋮ → «Εγκατάσταση εφαρμογής». The hedgehog icon appears; the app opens full screen. | |
| 2 | Storage is permanent | Open the installed app → lock (top left) → parent screen. It says «Η αποθήκευση είναι μόνιμη». | |
| 3 | Sound unlocks on «Πάμε!» | Tap «Πάμε!». The welcome instruction plays. | |
| 4 | Pictures and font | Stations and word pictures are the OpenMoji drawings (same as on the PC), not the tablet's own emoji. Letters use the reading font (single-storey «α»). | |
| 5 | Recording and playback | Parent screen → Ήχος → Οδηγίες → «Ηχογράφηση» on one line, «Τέλος», then «Άκουσε». Allow the microphone when asked. | |
| 6 | Recording survives closing the app | Close the app fully (swipe it away), reopen, play the same recording. | |
| 7 | Offline | Turn on airplane mode. Open the app from the home screen. Play a whole session (3 rounds). | |
| 8 | Data survives a restart | Restart the tablet. Village items, stars and the parent settings are all still there. | |
| 9 | Export and import | Parent screen → Αντίγραφο ασφαλείας → «Εξαγωγή»; save the file (Files / Downloads). Change a setting, then «Εισαγωγή» the file: the setting is back. | |
| 10 | Update only between rounds | After a new version is published: open the app. It updates on the start screen (or via the parent screen), never during a round. | |
| 11 | Daily limit | Set 5 minutes. Play: the current round finishes, then the mascot says «Τα λέμε αύριο!» and no new session starts. Reopening the app does not reset it. | |
| 12 | Portrait and landscape | Rotate during a game: nothing is cut off or hidden at the edges. | |
